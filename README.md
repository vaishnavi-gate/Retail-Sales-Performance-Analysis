Retail Sales Performance & Customer Analysis
Project Overview

An end-to-end Data Analytics project using the Sample Superstore dataset to analyse retail sales, profit, products, regions, and customer behaviour.

Tools & Technologies
Excel: Data exploration and PivotTables
Python: Data cleaning and Exploratory Data Analysis (EDA)
Pandas & NumPy: Data manipulation
SQL: Data analysis using Google BigQuery
Power BI: Interactive dashboards and visualisation
Project Workflow
Data exploration using Excel.
Data cleaning and preprocessing using Python.
Exploratory Data Analysis (EDA).
Customer analysis and RFM segmentation.
SQL analysis using Google BigQuery.
Interactive dashboard development using Power BI.
Business insights and recommendations.


Key Analysis
Sales and profit performance
Regional sales analysis
Product and category performance
Customer segmentation
Monthly sales trends
Discount and profitability analysis

Dataset
Source: Sample Superstore Dataset – Kaggle
