# Retail Sales Performance & Customer Analysis

## Project Overview

This project focuses on analysing retail sales data to understand sales trends, profitability, regional performance, product performance, and customer behaviour. It uses Excel, Python, SQL, and Power BI to generate meaningful business insights.

## Objectives

The main objective is to analyse sales and profit, identify top-performing products and regions, understand customer purchasing behaviour, and support data-driven business decisions through visualisation.

## Dataset

The project uses the **Sample Superstore Dataset** from [Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final), which contains order, customer, product, sales, discount, and profit information.

## Tools & Technologies

* **Excel:** Data exploration and PivotTables.
* **Python:** Data cleaning and exploratory data analysis.
* **Pandas & NumPy:** Data manipulation and analysis.
* **Matplotlib & Seaborn:** Data visualisation.
* **SQL & Google BigQuery:** Database querying and analysis.
* **Power BI:** Interactive dashboards and business reporting.

## Project Methodology

The project involves data exploration and cleaning, exploratory data analysis, customer analysis using RFM segmentation, SQL-based business analysis, and interactive dashboard development using Power BI.

## Key Analysis Areas

The analysis covers sales and profit performance, regional performance, product and category analysis, customer segmentation, monthly sales trends, and discount impact on profitability.

## Power BI Dashboard

The planned dashboard consists of three pages: Sales Overview, Product Analysis, and Customer Analysis, providing interactive visualisations and key performance indicators.
